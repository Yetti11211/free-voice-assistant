# Установка тестового APK

1. Скачайте `FreeVoiceAssistant-0.3.4-audit-arm64.apk` из Releases на Android 12+ (ARM64).
2. Откройте APK. Разрешите установку для приложения, через которое открыли файл, если Android попросит.
3. Запустите «Свободный ассистент» и скачайте модель (977 МБ) по Wi-Fi.
4. Подготовьте русский офлайн-пакет распознавания речи и локальный голос TTS.
5. Разрешите микрофон и уведомления. Нажмите «Начать беседу».
6. Для первой проверки оставьте «Разрешить перебивание» выключенным. Включайте его только с наушниками.
7. «Режим суфлёра» показывает ответ без озвучивания.

Для работы с выключенным экраном оставьте постоянное уведомление и при необходимости разрешите фоновую работу в настройках батареи. Поддержка зависит от устройства.

При ошибке установки проверьте Android 12+ и ARM64. При конфликте подписи с другой сборкой не удаляйте приложение до сохранения нужных данных; обратитесь к разработчику.

Контрольная сумма опубликована рядом с APK в `SHA256SUMS.txt`.
