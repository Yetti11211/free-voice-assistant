# Свободный ассистент · Android

Голосовой AI-ассистент от **Yetti Dev / Dream Team**. Распознаёт русскую речь, создаёт ответ локально на телефоне и озвучивает его. Есть потоковый текст ответа и тихий режим суфлёра.

**Публичная страница приложения: описание и готовый APK. Исходный код приложения не публикуется.**

## Скачать и установить

APK размещается в разделе **Releases** этого репозитория. Выберите файл `FreeVoiceAssistant-0.3.4-audit-arm64.apk`, затем следуйте [инструкции](INSTALL.md).

Версия **0.3.4-audit** — тестовая сборка, подписанная отладочным ключом. Это прототип для знакомства и проверки на совместимом телефоне, а не стабильный релиз. Реальная акустика и работа при выключенном экране требуют проверки на вашем устройстве.

## Что реализовано

- Голосовой диалог с контекстом беседы.
- Qwen3-1.7B на телефоне через Google LiteRT-LM, без собственного сервера и ключа API.
- LIVE-текст распознанной речи и потоковый вывод ответа.
- Озвучивание системным Android TTS и текстовый режим суфлёра.
- Защита от повторов и эха: по умолчанию микрофон возобновляет работу после окончания ответа.
- Перебивание ответа — отдельный режим для наушников.
- Фоновая служба с постоянным уведомлением.

## Требования

Android **12+**, архитектура **ARM64**, рекомендуется от **6 ГБ RAM** и около **3 ГБ свободного места**. Нужны локальные русский речевой пакет и голос TTS. Модель скачивается отдельно при первом запуске (977 МБ); после подготовки компонентов беседа рассчитана на работу без интернета.

## Проверки

Для этой сборки пройдены 5 автоматических антиэхо-тестов и проверка подписи APK. Android Lint: 0 ошибок по отчёту сборки. Это не заменяет проверку микрофона, динамика и энергосбережения на реальном телефоне.
